# 🚀 Team Task Manager (TaskFlow)

A full-stack web application to manage team tasks, projects, and workflows with role-based access.

---

## 📌 Features

* 🔐 User Authentication (Login / Signup)
* 👥 Role-based access (Admin / Member)
* 📁 Project management
* ✅ Task creation & assignment
* 📊 Task status tracking (Pending, In Progress, Completed)
* ⏰ Reminders & due dates
* 🧑‍🤝‍🧑 Team member management
* 📈 Dashboard analytics

---

## 🛠️ Tech Stack

### Frontend

* React (Vite)
* Tailwind CSS
* React Router

### Backend

* Node.js
* Express.js
* MongoDB (Mongoose)
* JWT Authentication

---

## ⚙️ Installation (Local Setup)

### 1️⃣ Clone Repository

```bash
git clone https://github.com/SujalDesale/team-task-manager.git
cd team-task-manager
```

---

### 2️⃣ Backend Setup

```bash
cd backend
npm install
```

Create `.env`:

```
MONGO_URI=your_mongodb_uri
JWT_SECRET=secret123
```

Run:

```bash
npm start
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
